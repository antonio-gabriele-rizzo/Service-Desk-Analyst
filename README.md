# Project Overview

This repository documents my hands-on Service Desk Analyst and IT Support laboratory, developed to build practical experience with ServiceNow, incident management and the technical environments commonly used to investigate and resolve user issues.

Rather than treating Service Desk work as a purely theoretical subject, every chapter is designed around a practical workflow. The project combines ServiceNow ticket management with supporting Microsoft 365, Microsoft Entra ID, Windows Server, Active Directory, networking and endpoint troubleshooting environments where appropriate.

The project begins with the configuration of a ServiceNow Personal Developer Instance (PDI) and progresses into realistic Service Desk incident scenarios. Each incident will follow the complete workflow from the initial user contact through information gathering, categorisation, troubleshooting, documentation, escalation, communication, resolution and closure.

This is an ongoing practical project. New chapters and realistic Service Desk scenarios will be added regularly as the project develops, new experience is gained and additional Service Desk situations are identified. There is intentionally no fixed final chapter.

Every chapter will combine detailed explanations, practical procedures, screenshots and verification steps, demonstrating hands-on experience while maintaining a professional GitHub portfolio standard.

# Project Objectives

Throughout this project, I will develop practical experience with the day-to-day activities performed by a Service Desk Analyst.

The primary objectives of this repository are to:

- Configure and use a ServiceNow Personal Developer Instance.
- Understand the Service Desk incident lifecycle.
- Create and document incidents correctly.
- Gather relevant information from users.
- Categorise incidents accurately.
- Assess impact and urgency.
- Determine incident priority.
- Document troubleshooting using work notes.
- Communicate with users using customer-facing comments.
- Escalate incidents when required.
- Understand assignment groups and ticket ownership.
- Work with Service Level Agreements (SLAs).
- Resolve and close incidents correctly.
- Practise Microsoft 365 support scenarios.
- Practise Active Directory support scenarios.
- Troubleshoot Windows endpoints, networking, hardware and common IT issues.
- Produce professional technical documentation suitable for a GitHub portfolio.

# Conclusion

This repository documents the development of practical Service Desk Analyst skills through hands-on work with ServiceNow and supporting technical environments.

The project does not attempt to simulate a fixed training course with a predetermined number of chapters. Instead, it is an ongoing portfolio that grows as new Service Desk scenarios, technical problems and practical experience are added.

The objective is to demonstrate not only how to create a ticket, but how a Service Desk Analyst approaches a user problem systematically: gathering information, assessing the incident, troubleshooting, documenting actions, communicating with the user, escalating when necessary and completing the ticket correctly.

As the project develops, the ServiceNow workflow will be combined with real technical demonstrations from the TechLab365 Microsoft 365 and Windows Server laboratories where appropriate.

The result will be a continuously expanding portfolio that demonstrates practical Service Desk methodology together with the underlying technical skills required to support users in a modern IT environment.
