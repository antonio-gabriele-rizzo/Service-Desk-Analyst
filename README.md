# Service Desk Analyst – Practical IT Service Desk Lab

A hands-on portfolio project designed to demonstrate practical **Service Desk Analyst / IT Support** workflows using ServiceNow and supporting TechLab365 environments.

The project is deliberately built as a growing practical lab rather than a fixed course. New realistic incidents can be added indefinitely as additional chapters.

## Project Objectives

This project is designed to demonstrate practical experience with:

- Service Desk incident management
- ServiceNow ticket handling
- Information gathering
- Incident categorisation
- Impact, urgency and priority
- Troubleshooting methodology
- Work notes and customer-facing comments
- Escalation and assignment
- Service Level Agreements (SLAs)
- Resolution and closure
- Microsoft 365 troubleshooting
- Active Directory troubleshooting
- Professional user communication
- Security and data-protection considerations

## Lab Environment

The project uses a combination of:

- ServiceNow Personal Developer Instance (PDI)
- Microsoft 365 TechLab tenant
- Windows Server / Active Directory home lab
- Windows client virtual machines where appropriate
- Other TechLab365 environments when technically useful

The ServiceNow environment is used for the ticket-management workflow. Supporting TechLab365 environments are used where a scenario requires a real technical investigation or remediation.

## Chapter Structure

### 01 – ServiceNow Developer Instance Setup and Configuration
**Status: Completed**

Creates and verifies the ServiceNow Personal Developer Instance and reaches the Incident management interface used for the practical exercises.

### 02 – Service Desk Incident Simulation
**Status: Planned**

Begins the simulated Service Desk workflow with realistic user contacts and incidents.

### 03 onwards
Additional incident and Service Desk chapters will be added progressively.

There is intentionally **no fixed final chapter**. New realistic scenarios can be added whenever they are identified or learned.

## Important Evidence and Confidentiality Note

Screenshots in this portfolio are taken from the author's lab environment or from ServiceNow demonstration data.

Any names, email addresses or other identities visible in ServiceNow demonstration screens are **synthetic/demo data and do not represent real people**.

No Presidio confidential information, customer information, internal ticket numbers, credentials, internal URLs or proprietary procedures will be included.

Real workplace experiences may be converted into generic, anonymised scenarios before being documented in this repository.
